# Getting help

1. Check [docs/troubleshooting.md](docs/troubleshooting.md). Every error message
   starts with a `BML-` code, and [docs/errors.md](docs/errors.md) explains each code
   and how to correct it.
2. Search existing issues in this repository.
3. Open an issue:
   - **Bug report**: something does not work as documented.
   - **Feature request**: something you need that BoundML does not do.
   - **Workload report**: you tried BoundML on a real workload. This is the most
     useful feedback for an early release, whether it worked or not.

Please include `boundml version` output, your platform, and the exact command with
its full output (`--json` output is ideal).

Security problems: see [SECURITY.md](SECURITY.md) and do not post them publicly.

BoundML is maintained on a best-effort basis; there is no commercial support.
